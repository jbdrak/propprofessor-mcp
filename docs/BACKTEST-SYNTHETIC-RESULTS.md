- TIER 1 (strong_sharp_move scenarios) clears the 50% moneyline base rate,
  confirming the ranking engine rewards supportive movement + deep consensus + CLV.
- TIER 1 outperforms TIER 3 (stable_no_edge), so the tier system differentiates
  the top from the coin-flip middle.
- TIER 4 vs TIER 2 ordering is not monotonic in synthetic data: moneyline
  outcomes are ~50/50, so the adverse-movement flag alone does not make a pick
  lose. This is a known limitation of the synthetic generator, not a proven
  model defect. Real validation requires settled results from the live API
  (snapshots captured manually, then resolved).

## Running it yourself

```
node scripts/backtest-synthetic.js --scenarios=1500 --verbose
```

The default PRNG is `Math.random()`; pass `setRandomSeed(20260826)` for the
deterministic results shown above. No network calls are made — the script
generates scenarios locally, so it complies with the manual-only PropProfessor
policy.
